# HotelScout

HotelScout — учебное веб-приложение для наблюдения за публичными ценами гостиниц. Первый источник данных — результаты Google Hotels, получаемые через SerpApi.

## Первый запуск

1. Скопируйте `.env.example` в `.env`.
2. Добавьте личный ключ SerpApi в `SERPAPI_API_KEY`.
3. Запустите приложение:

```powershell
docker compose up --build
```

После запуска:

- веб-интерфейс: <http://localhost:5173>;
- проверка API: <http://localhost:3000/health>.

Остановить приложение:

```powershell
docker compose down
```

Данные PostgreSQL сохраняются в именованном Docker-томе `postgres_data` и не удаляются обычной командой `docker compose down`.

## Текущие возможности

- форма поиска по городу, датам и числу гостей;
- серверный запрос к SerpApi без раскрытия ключа браузеру;
- минимальная проверка внешнего JSON;
- нормализация гостиниц и цен;
- сохранение запуска и предложений в PostgreSQL;
- отображение результата в таблице Vue;
- фиксация ошибок внешнего источника в базе.

## Структура

- `api` — Fastify, TypeScript, SerpApi и PostgreSQL;
- `web` — Vue 3, TypeScript и Vite;
- `database/migrations` — SQL-миграции базы;
- `compose.yaml` — совместный запуск компонентов.

## Безопасность

Файл `.env` исключён из Git. API-ключ нельзя помещать в исходный код, Vue-приложение или сообщения об ошибках.
